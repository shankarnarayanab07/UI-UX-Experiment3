## Exercise
Heuristic Evaluation of an Existing Mobile Application

## Aim

To evaluate the usability of an existing mobile application using Nielsen's Heuristic Evaluation principles, compare it with a competing application, and propose design improvements to enhance the overall user experience.

## What is Heuristic Evaluation?

Heuristic Evaluation is a usability inspection method in which a designer evaluates an interface based on Jakob Nielsen's 10 usability principles. It helps identify usability issues and improve the user experience.

## Nielsen's 10 Heuristics

| Heuristic | Meaning |
|---|---|
| Visibility of System Status | The system should always keep users informed about what is happening. |
| Match Between System and Real World | Use familiar language, icons, and concepts. |
| User Control and Freedom | Allow users to undo actions, cancel operations, or go back easily. |
| Consistency and Standards | Maintain consistent layouts, colors, icons, and interactions. |
| Error Prevention | Prevent user mistakes before they occur. |
| Recognition Rather Than Recall | Display options instead of expecting users to remember them. |
| Flexibility and Efficiency of Use | Support both new and experienced users. |
| Aesthetic and Minimalist Design | Keep the interface clean and avoid unnecessary elements. |
| Help Users Recognize, Diagnose, and Recover from Errors | Show clear error messages with solutions. |
| Help and Documentation | Provide guidance, FAQs, or tutorials when needed. |

## Existing App Selected: Instagram

### Problems Identified in Instagram

| Nielsen's Heuristic | Observation |
|---|---|
| Visibility of System Status | Upload progress is visible, but some background processing (such as feed refresh) is not always clear. |
| Match Between System and Real World | Uses familiar icons and terms like Stories, Reels, and Messages. |
| User Control and Freedom | Deleted posts can be restored, but some actions require several steps to undo. |
| Consistency and Standards | The interface is consistent throughout the application. |
| Error Prevention | Confirmation appears before deleting posts, but accidental Reel interactions are common. |
| Recognition Rather Than Recall | Icons are recognizable, although some newer features are hidden inside menus. |
| Flexibility and Efficiency | Offers shortcuts, saved posts, and quick sharing for experienced users. |
| Aesthetic and Minimalist Design | Modern and visually appealing, but the home feed can become crowded with ads and suggested content. |
| Error Recovery | Error messages are simple but sometimes do not explain the exact problem. |
| Help and Documentation | Help Center and reporting options are available but difficult to locate. |

## Compare and Analyze the UX of Competing Apps

### Apps Compared

- Instagram
- Snapchat

### UX Comparison Table

| Feature | Instagram | Snapchat |
|---|---|---|
| Home Screen Simplicity | Clean feed with bottom navigation | Opens directly to the camera, which may confuse new users |
| Search Speed | Fast and accurate | Fast but mainly focused on friends and content |
| Content Discovery | Excellent Explore page and Reels | Discover and Spotlight available but less prominent |
| Story Visibility | Stories appear clearly at the top | Stories are inside the Friends section |
| Media Sharing | Easy photo, video, Reel, and Story uploads | Quick Snap sharing with disappearing messages |
| Navigation | Simple bottom navigation bar | Swipe-based navigation with fewer visible buttons |
| Overall UX | Easy, intuitive, and beginner-friendly | Fun, interactive, but requires learning gestures |

## Analysis

### Instagram

**Strengths**

- Clean and modern interface.
- Easy navigation with bottom menu.
- Excellent content discovery through Explore and Reels.
- Smooth media upload process.
- Suitable for beginners and experienced users.

**Weaknesses**

- Too many advertisements and suggested posts.
- Reels often dominate the home feed.
- Privacy settings are spread across multiple menus.
- Some advanced features are difficult to find.

### Snapchat

**Strengths**

- Camera opens instantly for quick sharing.
- Excellent AR filters and creative lenses.
- Private communication through disappearing messages.
- Bitmoji integration enhances personalization.

**Weaknesses**

- Swipe navigation is difficult for first-time users.
- Important features are hidden behind gestures.
- Less intuitive interface compared to Instagram.
- Discover section can appear cluttered.

## Develop and Incorporate Required Changes

### Proposed Improvements for Instagram

1. Reduce the number of advertisements and suggested posts in the home feed.
2. Provide better customization for feed recommendations.
3. Simplify privacy and account settings.
4. Improve accessibility by adding more descriptive labels for icons.
5. Display clearer explanations when uploads fail.

### Before vs After (Simple Explanation)

| Before | After |
|---|---|
| Home feed contains many ads and suggested posts. | Display fewer ads and allow users to customize recommendations. |
| Privacy settings are spread across multiple menus. | Group all privacy settings into a single, easy-to-find section. |
| Upload errors provide limited information. | Show detailed error messages with suggestions to resolve the issue. |
| Some features are hidden inside menus. | Place frequently used features in visible and easily accessible locations. |

## Conclusion

Instagram offers a clean, modern, and user-friendly interface that makes content browsing and sharing simple for users of all experience levels. Compared to Snapchat, Instagram provides easier navigation, better content discovery, and a more intuitive overall user experience.

Snapchat excels in creativity and private communication with its camera-first approach and AR features, but its gesture-based navigation can make it less accessible for beginners.

Implementing the proposed improvements would further enhance Instagram's usability, accessibility, and overall user satisfaction.
